Smart Food Rescue 🍱

About the Project

Smart Food Rescue is a web application that connects food donors with people who need food. It helps reduce food wastage by sharing surplus food with recipients.

Main Features

- User Registration and Login
- Donor and Recipient Roles
- Food Donation Management
- View Available Food
- Claim Available Food
- Secure User Authentication

Technologies Used

- Frontend: React, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT

User Roles

Donor: Can add surplus food and manage food listings.

Recipient: Can view available food and claim food.

Project Goal

To reduce food wastage and help people by connecting food donors with recipients.
